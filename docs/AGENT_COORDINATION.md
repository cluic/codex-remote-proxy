## M2E/V8 Shared Contract Lock

- Metrics is independent from Capture and Activity. Capture configuration and `traffic.sqlite3` are unchanged.
- Worker observations contain only strict generation, result enum, bounded credential-screened model ID or null, bounded Token integers or null, and fixed latency-bin indexes. Request IDs, URLs, headers, bodies, session/thread IDs, credentials, status text, and raw errors are prohibited.
- Supervisor maps generation to Provider, aggregates UTC hourly buckets, retains seven days, persists strict schema 1 privately, and treats every write/flush failure as non-blocking degradation.
- `GET /api/v1/metrics/overview?window=24h|7d` is authenticated and read-only, available to cookie read-only sessions, rejects unknown/repeated query fields, and returns bounded summaries, series, Provider/model distributions, and data-quality counters.
- Frontend source is build-time only. Published UI remains exactly `index.html`, `app.js`, and `styles.css` with no dynamic chunks, source maps, CDN, telemetry, remote fonts, inline scripts/styles, or CSP relaxation.
- Permanent navigation is Overview, Providers, disabled Forwarding Records, Activity, and System. Setup is derived and conditional. Forwarding Records has no route, request, mock data, or Capture control.
